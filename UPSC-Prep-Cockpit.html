Round strategy

R1: answer only what you are sure of in ~60s. R2: needs elimination. R3: leave for the end. In R1 review you get a second pass over R2 + R3 before final submission.

Weekly CSAT-through-PYQ Drill

For each real CSAT paper: solve under 120 min → classify every error → re-solve without a timer → write the logic, not the answer. Tick each week.

Logic-first rule

For every CSAT question, write one line: "I know this because…" If you can't, the formula is doing the thinking for you — which is exactly what unfamiliar-pattern questions punish.

What this is NOT

  • Not the Decode Civils course — no affiliation, no login, no payment, no access to their videos or notes.
  • No live classes, no recorded lectures, no human mentor sessions, no real peer group.
  • Built-in questions are original exam-pattern practice items, not UPSC PYQs. Download real papers free from the official archive linked above and import them.
  • No cloud sync: all progress lives in this browser's local storage. Use Export in Settings to back up.
